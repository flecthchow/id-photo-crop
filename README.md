# 证件照裁剪

按固定尺寸（1寸、2寸等）裁剪照片的网页小工具。全部在浏览器本地处理，照片不会上传。

在线使用：https://flecthchow.github.io/id-photo-crop/

## 功能

- 内置尺寸（毫米）：1寸 25×35、小1寸 22×32、大1寸 33×48、2寸 35×49、小2寸 35×45、大2寸 35×53、5寸、6寸，也可自定义（毫米或像素）
- 拖动、缩放（滚轮 / 双指）、微调角度、90° 旋转，带头顶 / 下巴参考线
- 导出 JPG / PNG，可设分辨率（默认 300 DPI）并写入文件，可限制文件大小（KB）
- 排版打印：6寸、5寸、7寸相纸或 A4，自动排满并画裁切线

## 使用

直接打开 `index.html` 即可，无需安装，单个文件无外部依赖。
